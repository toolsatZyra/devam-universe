# Ritual-calendar all-year selected denominator (superseded completion boundary)

This 132-item demand-prioritized inventory remains a useful checkpoint, but it
is no longer the completion boundary. The user's broader day-guidance scope is
frozen in `ritual-calendar-comprehensive-census-v3.json`. Nothing in this file
should be read as a claim that the comprehensive home/temple-participant
library is complete.

The first checkpoint proved the 104-slug September-December baseline plus one
Mahashivaratri lane. It did not prove the continuing goal's all-year expansion.

Version 2 freezes a 132-item denominator before further prose is authored. It
adds seven recurring families and twenty named January-August annual lanes.
The selection is demand-prioritized using current Government of India holiday
calendars, official tourism discovery, existing Devam recurring contracts, and
the product's hero-ownership boundaries. It is not a claim to enumerate every
Indian observance.

At freeze:

- 106 items are complete: the prior 105 plus the already all-year weekday rule;
- 25 items require research, authoring, calendar extension, or owner proposals;
- one Upakarma/Avani Avittam/Janai Purnima umbrella is blocked inside this
  denominator until distinct sampradaya and eligibility lanes replace the
  misleading umbrella; and
- no new annual prose is counted merely from a holiday name or tourism page.
