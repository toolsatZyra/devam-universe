# Independent Artificial-Wisdom Foundations

**Date:** 2026-08-07  
**Status:** current conceptual research entry point

The first Sārthi artificial-wisdom research package in this directory began too close to Devam's current product assumptions. It remains preserved as an implementation-oriented hypothesis and source of useful domain research, but it is not the controlling definition or architecture.

The corrected programme is under `independent-foundations/`. It proceeds in this order:

1. distinguish wisdom from intelligence, expertise, insight, rationality, morality, prudence, common sense, judgment, and charisma;
2. compare competing scientific and philosophical theories;
3. derive and adversarially test a domain-independent architecture;
4. define how any vertical domain instantiates that architecture; and
5. treat Sārthi as one application rather than the source of the theory.

Start with:

- `independent-foundations/FOUNDATIONAL_RESEARCH_HANDOFF.md` — self-contained recommendation, architecture, evaluation, sources, roadmap, and Sārthi integration;
- `independent-foundations/CONSTRUCT_TAXONOMY.md` — operational definitions and capability lattice;
- `independent-foundations/THEORY_OF_WISDOM.md` — competing theories and the proposed causal core;
- `independent-foundations/GENERAL_ARTIFICIAL_WISDOM_ARCHITECTURE.md` — domain-independent architecture;
- `independent-foundations/ADVERSARIAL_REVIEW_V2.md` — strongest objections, corrections, and falsifiers; and
- `independent-foundations/FOUNDATIONAL_ARTIFACT_MANIFEST.sha256` — artifact integrity manifest.

The programme's current claim ceiling is deliberately narrow: it has produced a falsifiable architecture for **wisdom-supporting system performance**, not proof of a wise machine or a solved theory of general artificial wisdom.
